Untuk mendapatkan **Meta App ID** dan **Meta App Secret**, Anda harus membuat aplikasi terlebih dahulu di **Meta for Developers**. Berikut langkah-langkahnya.

### 1. Masuk ke Meta for Developers

Buka:

**[Meta for Developers](https://developers.facebook.com/?utm_source=chatgpt.com)**

Login menggunakan akun Facebook Anda. Jika belum pernah menjadi developer, Anda akan diminta mengaktifkan akun developer terlebih dahulu. ([CodexWorld][1])

---

### 2. Buat App Baru

1. Klik **My Apps**
2. Klik **Create App**
3. Pilih jenis aplikasi yang sesuai.

Jika untuk:

* WhatsApp Cloud API → pilih **Business**
* Facebook Login → pilih **Consumer**
* Marketing API → pilih **Business**

Isi:

* App Name
* Contact Email
* Business Portfolio (jika ada)

Lalu klik **Create App**. ([CodexWorld][1])

---

### 3. Ambil App ID

Masuk ke:

**Dashboard → Settings → Basic**

Di sana akan terlihat:

```
App ID
123456789012345
```

Itulah **Meta App ID** Anda. ([Themesic Docs][2])

---

### 4. Ambil App Secret

Masih di halaman yang sama:

```
Settings
   └── Basic
```

Anda akan melihat:

```
App Secret
*************
[Show]
```

Klik **Show**, kemudian masukkan password Facebook Anda.

Setelah diverifikasi akan muncul:

```
a1b2c3d4e5f6g7...
```

Itulah **Meta App Secret** Anda. ([Themesic Docs][2])

## Jika untuk WhatsApp Cloud API

Selain **App ID** dan **App Secret**, Anda juga biasanya memerlukan:

* App ID
* App Secret
* Access Token
* Phone Number ID
* WhatsApp Business Account ID (WABA ID)
* Verify Token (dibuat sendiri)
* Webhook URL
