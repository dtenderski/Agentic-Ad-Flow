Baik, kita lanjutkan dengan rancangan **integrasi Meta Ads dengan aplikasi lain**: pembayaran seperti [**Scalev.id**](http://Scalev.id), deployment/app builder seperti [**Replit.com**](http://Replit.com), **Meta Pixel**, **Webhook**, **Conversion API**, dan **Meta Ads Analytics** untuk pembelajaran iklan berikutnya.

Bagian ini menjadikan framework kita naik level dari:

> **Research-to-Ads Blueprint Framework**
> 

menjadi:

> **Research-to-Conversion-to-Learning Framework**
> 

Artinya sistem tidak hanya membuat blueprint iklan, tetapi juga menghubungkan iklan dengan transaksi, pembayaran, data lead, perilaku pengunjung, dan hasil performa untuk memperbaiki campaign berikutnya.

flowchart TD

# 44. Meta Pixel + CAPI Deduplication

Jika event dikirim dari browser Pixel dan server CAPI, harus ada deduplication.

## 44.1 Event ID

Gunakan `event_id` yang sama untuk Pixel dan CAPI.

Contoh:

```
event_id = lead_12345
event_id = purchase_order_98765
```

Browser mengirim:

```jsx
fbq('track', 'Purchase', {
  value: 500000,
  currency: 'IDR'
}, {
  eventID: 'purchase_order_98765'
});
```

Server mengirim CAPI dengan:

```json
{
  "event_name": "Purchase",
  "event_id": "purchase_order_98765",
  "event_time": 1784740000,
  "action_source": "website"
}
```

Meta akan mengenali bahwa keduanya event yang sama.

# 50. Optimization Rules

## 50.1 Rule untuk CTR

| Kondisi | Interpretasi | Rekomendasi |
| --- | --- | --- |
| CTR rendah | Hook/creative kurang menarik | Ganti hook/visual |
| CTR tinggi tapi lead rendah | Landing/form bermasalah | Perbaiki funnel |
| CTR tinggi + CPL rendah | Creative cocok | Scale testing |
| CTR tinggi + lead buruk | Copy terlalu luas/clickbait | Tambah qualifier |

---

## 50.2 Rule untuk CPC

| Kondisi | Interpretasi | Rekomendasi |
| --- | --- | --- |
| CPC tinggi | Audience mahal/creative kurang relevan | Test audience baru |
| CPC rendah tapi lead rendah | Klik tidak berkualitas | Perbaiki targeting/copy |
| CPC stabil | Market cukup responsif | Lanjut monitoring |

---

## 50.3 Rule untuk CPL

| Kondisi | Interpretasi | Rekomendasi |
| --- | --- | --- |
| CPL rendah | Lead murah | Cek kualitas lead |
| CPL tinggi | Offer/funnel kurang kuat | Perbaiki offer |
| CPL naik dari waktu ke waktu | Creative fatigue | Refresh creative |
| CPL rendah tapi closing rendah | Lead tidak qualified | Tambahkan form question |

---

## 50.4 Rule untuk Purchase / ROAS

| Kondisi | Interpretasi | Rekomendasi |
| --- | --- | --- |
| Purchase ada, ROAS positif | Campaign layak scale | Naikkan budget bertahap |
| Lead banyak, purchase sedikit | Follow-up/closing lemah | Audit sales process |
| AddToCart tinggi, Purchase rendah | Checkout/payment friction | Audit payment page |
| Purchase tidak tercatat | Tracking error | Periksa Pixel/CAPI |

# 54. Contoh Pseudocode Webhook Payment to CAPI

```jsx
app.post('/webhooks/scalev', async (req, res) => {
  const rawPayload = req.body;

  // 1. Verify webhook signature
  const isValid = verifyScalevSignature(req);
  if (!isValid) {
    return res.status(401).json({ error: 'Invalid signature' });
  }

  // 2. Normalize event
  const event = normalizeScalevPayload(rawPayload);

  // 3. Check duplicate
  const exists = await db.webhookEvents.findByExternalId(event.event_id);
  if (exists) {
    return res.status(200).json({ status: 'duplicate_ignored' });
  }

  // 4. Save webhook event
  await db.webhookEvents.insert(event);

  // 5. If payment paid, create order
  if (event.event_type === 'payment.paid') {
    const order = await db.orders.upsert({
      external_payment_id: event.payment.payment_id,
      amount: event.payment.amount,
      currency: event.payment.currency,
      status: 'paid',
      paid_at: event.payment.paid_at,
      customer: event.customer,
      tracking: event.tracking
    });

    // 6. Send Purchase event to Meta CAPI
    await sendMetaCapiEvent({
      event_name: 'Purchase',
      event_id: `purchase_${order.id}`,
      event_time: Math.floor(Date.now() / 1000),
      action_source: 'website',
      user_data: {
        email: hash(event.customer.email),
        phone: hash(event.customer.phone),
        fbp: event.tracking.fbp,
        fbc: event.tracking.fbc,
        client_ip_address: event.tracking.client_ip,
        client_user_agent: event.tracking.user_agent
      },
      custom_data: {
        currency: event.payment.currency,
        value: event.payment.amount,
        order_id: order.id,
        content_name: event.product.name,
        content_ids: [event.product.product_id]
      }
    });

    // 7. Update learning data
    await learningService.recordConversion(order);
  }

  return res.status(200).json({ status: 'processed' });
});
```

# 55. Contoh Pseudocode Meta CAPI Sender

```jsx
async function sendMetaCapiEvent(event) {
  const payload = {
    data: [
      {
        event_name: event.event_name,
        event_time: event.event_time,
        event_id: event.event_id,
        action_source: event.action_source,
        user_data: event.user_data,
        custom_data: event.custom_data
      }
    ]
  };

  const response = await fetch(
    `https://graph.facebook.com/v20.0/${process.env.META_PIXEL_ID}/events?access_token=${process.env.META_CAPI_ACCESS_TOKEN}`,
    {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(payload)
    }
  );

  return response.json();
}
```
